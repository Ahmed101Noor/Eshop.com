
🛒 Eshop.com Project

## Overview

Eshop.com is a simple e-commerce website developed using core web technologies: HTML, CSS, and JavaScript. The project aims to provide users with a basic online shopping experience, including user registration and product browsing.

## 🧩 Project Structure

- **index.html**: The homepage displaying available products.
- **register.html**: A page for new user registration.
- **customer/**: Folder containing customer-related UI files.
- **css/**: Folder for styling files (CSS).
- **js/**: Folder for JavaScript files handling website behavior.

## ✅ Features

- Display of products on the homepage.
- User account registration functionality.
- Responsive design for various screen sizes.
- Well-structured codebase for easier maintenance and updates.


## 🚀 How to Run

1. Download the project files from the [repository](https://github.com/Ahmed101Noor/Eshop.com/tree/main).
2. Open `index.html` in a web browser to view the homepage.
3. To test the registration feature, open `register.html`.

## 📌 Notes

- Currently, there is no backend or database integration; all data is static.
- Future improvements could include login functionality, shopping cart, and database support.
